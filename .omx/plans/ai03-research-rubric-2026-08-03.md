# AI-03 Research Quality Rubric

- A digest is working memory, never citation-ready truth by itself.
- User annotations remain authored material; AI text remains inferred/structured output and can be incomplete or stale.
- Every direct-save path continues to use the existing local locator/artifact gate. QA-only material may inform the digest but cannot create a verified evidence row without a resolved source reference.
- Missing transcript, malformed Markdown, unavailable AI, and interrupted streams produce explicit review/waiting states rather than fabricated conclusions.
- Cross-paper consensus, counterexample, method and dataset checks remain deferred to the existing evidence-matrix gate; AI-03 must not shortcut them.
