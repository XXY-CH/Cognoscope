# KG-05 Adversarial Review

## Verdict

PASS. No unresolved P0/P1 findings remain.

## Findings And Disposition

- P1: locator kind was not checked against the source file type. Fixed by
  requiring PDF page locators for PDF files and valid EPUB CFI/location locators
  for EPUB files; mismatches remain visibly unresolved and non-navigable.
- P1: stale graph nodes could expose an enabled Reader action after a source was
  missing or soft-deleted. Fixed with active-file gating in both the view and the
  navigation callback.
- P1: the mobile inspector lacked dialog semantics, Escape handling, and focus
  restoration. Fixed with the existing `useFocusTrap` contract and mobile-only
  `role="dialog"`/`aria-modal` semantics.
- P1: duplicate evidence references could be rendered more than once. Fixed with
  deterministic anchor IDs and a seen-ID set before the 20-item cap.
- P2: stale `pendingLocator` could survive an invalid matrix query during an SPA
  transition. Fixed by clearing it on every Reader URL/file handoff and when a
  matrix row lookup fails.
- P2: malformed EPUB CFI strings could appear available. Fixed with an explicit
  `epubcfi(...)` shape check, while valid numeric locations remain supported.
- P3: evidence database failures looked like an empty state. Fixed with a
  separate visible error state in the graph inspector.

## Boundary Checks

- Graph edges remain read-only relation clues; no copy or citation action was
  added.
- Matrix rows and nested evidence items remain the only persisted evidence
  source; graph evidence is a non-persisted projection.
- Reader return context is fixed to the allowlisted graph route and node kind;
  no arbitrary return URL is accepted.
