# Summary — 关键词图谱规格

> Source: Deep Interview, 2026-07-30  
> Goal: 问清后直接实现

## 一句话
在知识图谱页**左右分栏**：左为现有论文关系图，右为新建**关键词图谱**；论文入图成功时，用摘要 AI 补词并与原文词**近义合并**（**每篇合计 ≤5**，原文优先），再按**共现 + 语义相似度**建边（本地共现保底，AI 补语义）；点击两侧节点**双向高亮**。

## 决策表

| 项 | 决策 |
|---|---|
| 展示 | 同页双画布，左论文 / 右关键词 |
| 单篇词数 | **合计 ≤5**（原文优先，不足再 AI 补） |
| AI 补词 | 自摘要生成，填满剩余名额 |
| 合并 | 语义近义合并；label 原文优先 |
| 触发 | 论文入图成功（status=in）时一并做 |
| 词边 | **本地共现**（同篇词两两）+ **AI 语义分**；`weight≈0.55×共现+0.45×语义` |
| 旧词输入 | 全量（本篇↔旧词语义与跨篇共现） |
| 联动 | 点词↔点论文双向高亮 |
| Demo | 不使用启发式 demo 边 |

## 建议数据（实现）
- `keywordNodes`: id, label, aliases[], paperNodeIds[] / links
- `keywordEdges`: source, target, weight
- 论文图保持现有 `graphNodes` / `graphEdges`
- 归属：词↔论文多对多（高亮用）

## 流水线
```
论文入图成功
  → 原文关键词截断 ≤5
  → AI(摘要) → 补满剩余名额（合计仍 ≤5）
  → 近义合并（原文 label 优先）→ 再截断 ≤5
  → upsert 关键词节点 + 挂接论文
  → 本地共现边（同篇两两）→ AI 语义分融合边权
  → 右画布刷新；左右选中态联动
```
