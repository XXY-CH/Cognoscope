# Keyword Generation & Merge

> Source: Deep Interview, 2026-07-30

## Key Points
- **每篇文章合计不超过 5 个关键词**（原文优先；不足再由 AI 从摘要补齐）
- 与原文关键词合并策略：**语义近义合并**（例：「协作学习」与「协同学习」合成同一节点）
- 触发时机：论文**成功入图（status=in）时一并执行**（与论文入图流水线耦合）

## Details
### 生成
- 原文 Keywords 先去重截断至 ≤5
- AI 仅补 `5 - 原文数` 个；原文已满 5 则跳过补词
- 近义合并后再做一次「原文优先」截断，确保挂接本篇的词 ≤5

### 合并（近义）
- 不能只靠字符串精确去重
- 需要近义判定：可能由**同一次或另一次 AI 调用**完成归一（canonical label）
- 归一后的 canonical 词成为关键词图谱中的**唯一节点**；多篇论文可挂到同一词节点

### 流水线位置
```
导入 → 抽摘要/原文关键词 →（可选）入图检查 AI
  → 论文入图成功
  → 原文截断 ≤5 → AI 补满剩余 → 近义合并 → 再截断 ≤5
  → 词间建边（共现 + 语义）
```
