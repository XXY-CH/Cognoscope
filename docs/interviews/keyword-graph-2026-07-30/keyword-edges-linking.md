# Keyword Edges & Cross-Graph Linking

> Source: Deep Interview, 2026-07-30

## Key Points
- 词间边：**本地共现保底** + **AI 语义分**，综合 `weight ≈ 0.55×共现 + 0.45×语义`（无手动连线）
- 建边范围：本篇挂接词 **两两共现**；本篇词 ↔ 全局旧词（语义 + 跨篇共现）
- 与论文图谱：**双向联动**——点关键词高亮相关论文节点；点论文高亮其关键词

## Details
### 词间建边
- **本地**：同篇 ≥2 词 → 两两建边（共现分≈0.7 + 默认语义），不依赖 AI / 不要求已有旧词
- **AI**：对候选对打 `semanticScore`，客户端再与共现分合成 `weight`；失败则保留共现边
- 打分：`weight ≈ 0.55×共现分 + 0.45×语义相似度`；`< 0.35` 丢弃
- 输出：边列表 `{source, target, weight}`
### 增量范围
- 每次入图只增量写入与本篇相关的边；不整图重算
- 第一篇入图：同篇词之间即有共现边（修复「无任何联系」）

### 跨画布联动（9D）
- 左/一侧：论文关系图；另一侧：关键词图
- 选中论文节点 → 关键词图高亮该论文挂接的所有词节点（及可选：其间的边）
- 选中关键词节点 → 论文图高亮挂有该词的所有论文节点
- 需要底层维护：**词节点 ↔ 论文 fileId/nodeId 多对多** 归属关系
